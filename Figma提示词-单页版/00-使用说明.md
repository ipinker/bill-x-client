# Figma AI 单页提示词使用说明

## 📁 文件结构

本文件夹包含 30 个独立的提示词文件，每个文件对应一个页面：

```
01-TabBar.md
02-Home-Todo.md
03-Billing-Entry.md
04-AI-Assistant.md
05-Profile.md
06-Bill-Details.md
... (共 30 个文件)
```

## 🎯 使用步骤

### 方法一：逐页生成（推荐，精度最高）

1. **打开 Figma**，按 `F` 创建 750px 宽度的 Frame
2. **命名 Frame**：如 `01-TabBar`
3. **打开对应文件**：`01-TabBar.md`
4. **复制全部内容**：Cmd/Ctrl + A，然后 Cmd/Ctrl + C
5. **调用 Figma AI**：
   - 选中 Frame
   - 按 `/` 或点击右侧 "Make Design"
   - 粘贴提示词
   - 点击生成
6. **等待生成**：约 10-30 秒
7. **微调细节**：检查颜色、圆角、间距
8. **重复步骤 1-7**：完成其他 29 个页面

### 方法二：批量创建 Frame（适合预先规划）

1. **创建 30 个 Frame**：
   - 按 `F` 创建第一个 750px Frame
   - 按 `Cmd/Ctrl + D` 复制
   - 排列成 6 行 × 5 列网格，间距 100px
   
2. **批量命名**：
   - 01-TabBar
   - 02-Home-Todo
   - 03-Billing-Entry
   - ... (共 30 个)

3. **逐个生成**：
   - 选中第一个 Frame
   - 打开 `01-TabBar.md`，复制内容
   - 调用 Figma AI，粘贴，生成
   - 选中下一个 Frame，重复

## ⚡ 快捷技巧

### 1. 快速创建 750px Frame
```
按 F → 点击画布 → 输入 750*1334 → 按 Enter 两次
```

### 2. 快速命名
```
选中 Frame → 双击图层名称 → 输入 "01-TabBar" → Enter
```

### 3. 快速复制提示词
```
打开 .md 文件 → Cmd/Ctrl + A → Cmd/Ctrl + C
```

### 4. 快速调用 AI
```
选中 Frame → 按 / → 粘贴 → 点击生成
```

## 🎨 生成后检查清单

每个页面生成后，检查以下内容：

- [ ] 主题色是否为 #7C4DFF（深紫色）
- [ ] 卡片圆角是否为 24px
- [ ] 按钮圆角是否为 16px
- [ ] 页面边距是否为 30px
- [ ] 导航栏高度是否为 88px
- [ ] 字号是否符合规范（48/36/32/28/24/22/20px）
- [ ] 阴影是否为 0 4px 20px rgba(0,0,0,0.08)

## 🔧 常见问题

**Q1: 生成的颜色不准确？**
- 生成后手动调整为 #7C4DFF
- 创建 Color Style 统一替换

**Q2: 布局比例不对？**
- 检查 Frame 宽度是否为 750px
- 重新生成，或手动调整

**Q3: 圆角不统一？**
- 选中所有卡片 → 右侧 Corner Radius 改为 24px

**Q4: AI 理解错误？**
- 简化提示词，去掉过于复杂的描述
- 分步生成，先生成主体，再添加细节
